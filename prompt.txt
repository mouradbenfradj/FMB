## PROMPT DE SYNTHÈSE - PROJET ASC (Aquaculture Suivi Concert)

---

### CONTEXTE DU PROJET

Application Symfony de gestion d'élevage de fruits de mer (huîtres et moules) en Tunisie (Lagune de Bizerte). L'application permet de suivre le cycle de vie complet de la production ostréicole et mytilicole.

---

### 1. ANALYSE DES ENTITÉS (src/Entity/)

L'application gère les entités suivantes:

| Entité | Rôle |
|--------|------|
| **Parc** | Parc d'élevage principal |
| **Filiere** | Rangée/ligne d'élevage dans le parc |
| **Segment** | Portion de filière avec emplacements |
| **Emplacement** | Place précise pour le matériel |
| **Flotteur** | Flotteur de support (volume, taux, kgf) |
| **FlotteurSegment** | Association flotteur-segment |
| **FruitDeMer** | Espèce (huître/moule) |
| **Corde** | Corde d'élevage |
| **Lanterne** | Panier/poche pour huîtres |
| **Stock** | Dépôt/zone de stockage |
| **Articles** | Produits utilisés |
| **StockArticle** | Quantité article en stock |
| **StockArticleSn** | Article avec numéro de série |
| **StockMateriel** | Classe abstraite (StockCorde, StockLanterne) |
| **Phase** | Étape du cycle (Pré-grossissement, Grossissement, Commercial) |
| **Processus** | Opération avec âge cible |

### 5. CRÉATIONS EFFECTUÉES

#### A. Service HuitreCalculator (src/Service/HuitreCalculator.php)
```php
class HuitreCalculator
- calculatePoidsParPiece($age) // 0.16g → 388g selon âge
- calculateTauxDeSurvie($age) // 97%
- calculatePoidsNet($age, $longeur, $quantiter)
- calculatePoidBrute($age, $longeur, $quantiter)
- getPhase($age) // PRE-GROSS, GROSS, COMMERCIALE
- getEtape($age) // NH+1, GH+1, H5, H4...
- getCategorie($age) // N°0, N°00, N°000...
```

#### B. Extension Twig Huitre (src/Twig/HuitreExtension.php)
```php
// Fonctions disponibles:
huitre_col_j($age)           // U/KG
huitre_col_k($age)           // Poids pièce (g)
huitre_col_l($age, $quantiter) // U/M
huitre_col_m($age)           // Survie %
huitre_col_n($age, $quantiter) // Survie/T0
huitre_col_o($age, $longeur, $quantiter) // Poids net KG
huitre_col_p($age, $longeur, $quantiter) // Poids brut KG
huitre_phase($age)
huitre_etape($age)
huitre_categorie($age)
```

### 7. ETAT ACTUEL DE LA PRODUCTION (templates/etat_actuel_prod/)

**Page**: `templates/etat_actuel_prod/etatActuelProd.html.twig`

**Statistiques actuelles affichées:**

- Remplissage Filière (%)
- Flottabilité Filière (%)
- Taille Filière (m)
- Total Emplacements (u)
- Emplacements Vides (u)
- Emplacements Remplis (u)
- Total Cordes (u)
- Total Cordes Huitre (u)
- Total Cordes Moule (u)
- Total Lanternes (u)
- Total Poches (u)
- Derniere Date De MAE
- Total Passages chaussettes (u)
- Segments

**Services utilisés:**
- `EtatActuelProdService` → appelle `FiliereService` et `SegmentService`
- `FiliereService` calcule les stats agrégées par filière
- `SegmentService` calcule les stats par segment

**Améliorations suggérées pour afficher plus d'informations:**

1. **Poids total**: Poids net/brut de toute la filière (calculé avec MouleCalculator/HuitreCalculator)
2. **Volume total**: Volume estimé de la filière
3. **Distribution par âge**: Nombre de cordes par tranche d'âge
4. **Répartition par espèce**: % huîtres vs % moules
5. **Capacité disponible**: Places restantes
6. **Alertes**: Warnings pour surcharge ou sous-utilisation

**Exemple de données à ajouter:**
```php
// Dans FiliereService:
- getPoidsNetTotal()     // Poids net total filière
- getPoidsBrutTotal()    // Poids brut total
- getVolumeTotal()       // Volume total estimé
- getAgeMoyen()          // Âge moyen des populations
- getPourcentageHuitre() // % huîtres
- getPourcentageMoule()  // % moules
- getCapaciteRestante()  // Places disponibles
- getAlerte()            // Warning si surcharge
```

#### D. ENTITÉS PRINCIPALES ET LEURS CHAMPS

**StockCorde (Corde en stock/élevage):**
```php
- quantiter        → Quantité de naissains (U)
- longeur         → Longueur de la corde (m)
- corde           → Référence à l'entité Corde
- chaussement     → Booléen: chaussé ou non
- dateassemblage  → Date d'assemblage
- datechaussement → Date de chaussement
```

**Corde (Référence cordes disponibles):**
```php
- longeur       → Longueur standard (m)
- quantiter     → Quantité disponible
- nom           → Nom de la corde
- fruitDeMer    → Huitre ou Moule
- parc          → Parc d'appartenance
```

**StockMateriel (Classe parent):**
```php
- datedecreation          → Date de création
- dateDeMiseAEau         → Date de mise à l'eau (MAE)
- datederetirement       → Date de retrait
- datederetraittransfert → Date de retrait pour transfert
- datedemaetransfert     → Date de mise pour transfert
- phase                  → Phase d'élevage actuelle
- processus              → Processus actuel
- pret                   → Disponible/prêt
- emplacement            → Emplacement actuel
```

#### F. FLUX DE DONNÉES

```
Formulaire MAE (saisie)
    ↓
StockCorde + StockMateriel
    ↓ (calcul)

    ↓
Processus = getProcessusParAge(âge)
    ↓
Phase = getPhaseParProcessus(processus)
    ↓ (calculs)
Poids net = calculatePoidsNet(âge, longeur, quantiter)
```

---

#### B. DONNÉES CALCULÉES DEPUIS L'ENTITÉ PROCESSUS

L'entité **Processus** contient:
```php
- nomProcessus  // Ex: "NH+1", "GH+1", "H5", "GM1"...
- age           // Âge cible en mois (ex: 1, 2, 3... 20)
- phase         // Relation vers Phase
```

| Donnée Calculée | Source | Méthode de calcul |
|----------------|--------|------------------|
| **Âge en mois** | `Processus.age` | Directement depuis `processus->getAge()` |
| **Phase** | `Processus.phase` | `processus->getPhase()->getNomPhase()` |
| **Libellé Article** | `Processus.nomProcessus` | Ex: "PRE-GROSS.-NH", "GROSS.-H" |
| **U/KG** | Calcul | `HuitreCalculator::calculateColJ(age)` |
| **Poids/pce (g)** | Calcul | `HuitreCalculator::calculatePoidsParPiece(age)` |
| **U/M** | Calcul | `MouleCalculator::calculateUiniterMetre(age, quantiter)` |
| **Survie %** | Constante | 97% (Huitre) / 90% (Moule) |
| **Survie/T0** | Calcul | `Calculator::calculateColN(age, quantiter)` |
| **POIDS NET** | Calcul | `Calculator::calculatePoidsNet(age, longeur, quantiter)` |
| **POIDS BRUT** | Calcul | `Calculator::calculatePoidBrute(age, longeur, quantiter)` |
| **Catégorie** | Calcul | `HuitreCalculator::getCategorie(age)` → N°0, N°00... |

---

#### C. FLUX COMPLET MAE

```
FORMULAIRE MAE (saisie)
├── Stock (choisi)
├── Corde (choisie)
├── FruitDeMer (espèce)
├── Article (choisi)
├── Lot/NumeroSerie (choisi)
├── datedeMAE ──────────────────────────→ StockMateriel.dateDeMiseAEau
├── densiter (Densité U) ───────────────→ StockCorde.quantiter
├── phase ──────────────────────────────→ StockMateriel.phase
└── processus ────────────────────────────→ StockMateriel.processus
                                            ↓
                          CALCULS (depuis Processus.age)
                          ├── âge = processus.age
                          ├── survie = 97% ou 90%
                          ├── poids/pce = calculatePoidsParPiece(âge)
                          ├── U/M = calculateUiniterMetre(âge, quantiter)
                          ├── POIDS NET = calculatePoidsNet(âge, longeur, quantiter)
                          └── POIDS BRUT = calculatePoidBrute(âge, longeur, quantiter)
```
